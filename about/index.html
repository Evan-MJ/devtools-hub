Our Mission

DevTools Hub provides a free, privacy-first collection of hundreds of online developer tools. Almost every tool runs entirely in your browser — your data, code, and files never leave your device. The exceptions are the AI tools, which send what you type to a third-party model provider so there is something to answer with; each one says so on its own page. We exist to make common developer tasks faster, easier, and more accessible to everyone.

Who We Are

DevTools Hub is built and maintained by BAOMING (Evan-MJ), an independent web developer focused on creating fast, reliable, and ethical developer tools. The project is hosted on Cloudflare Pages and powered entirely by static HTML, CSS, and client-side JavaScript.

Maintainer credentials: BAOMING (Evan-MJ) is an independent full-stack developer with 10+ years of professional experience in web technologies (HTML, CSS, JavaScript, Python, Rust). The maintainer's source code is publicly auditable on GitHub, and the file-processing tools ship with transparent client-side processing — no hidden servers, no obfuscation, no data exfiltration. See the Subprocessors page for every third party that receives data, and which tools involve each one.

Last reviewed: 2026-09-15 by BAOMING (Evan-MJ). Verified: every tool operational, zero tracking cookies, zero analytics that follow users across the web.

Technology

  • Frontend: Vanilla HTML, CSS, and JavaScript — no frameworks, no build step. All tools follow MDN Web Standards for cross-browser compatibility.
  • Hosting: Cloudflare Pages (global edge network with 330+ data centers).
  • APIs: Free tiers of Groq, NVIDIA NIM, Google Gemini, SiliconFlow, and others for AI features.
  • Storage: Cloudflare KV for optional user feedback (no personal data).

Privacy

We don't track users across the web, set advertising cookies, or collect personal data. We do count page views in a cookieless way (no identifier, no cross-site tracking) so we can see which tools people actually use. See our Privacy Policy for full details.
