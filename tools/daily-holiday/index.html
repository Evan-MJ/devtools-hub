About This Tool

Instantly find out what holiday falls on any date. This tool covers public holidays, bank holidays, optional holidays, and observances for over 100 countries and regions worldwide. Data is computed locally in your browser using the date-holidays library — no API calls, no server round-trips.

Why Use This?

Large language models cannot reliably answer "what holiday is today" because they lack real-time access to global holiday calendars and their training data becomes stale. AI models may confuse similar holiday names, invent holidays that don't exist, or miss country-specific observances. This tool computes holidays mathematically using a comprehensive, locally-stored dataset.

How It Works

1. Select a country or region from the dropdown
2. Choose a date (defaults to today)
3. Click "Find Holidays" to see all holidays for that date
4. Use the type tabs to filter by category (public, bank, optional, observance)

How many countries are supported?

Over 100 countries and their sub-regions (states, provinces) are supported. This includes all major economies and many smaller nations. The data is maintained by the date-holidays open-source project.

What do the holiday types mean?

Public — Legally recognized public holidays, typically with mandatory day off.
Bank — Banks are closed; most businesses follow.
Optional — Optional holiday; some employers may observe.
Observance — Not a holiday, but a recognized day (e.g., religious observances, commemorations).

Is this better than asking an AI?

Yes for factual, current holiday data. AI models hallucinate holidays, confuse dates, or miss regional variations. This tool uses a deterministic algorithm that computes the exact holiday for any date, in any supported country, with zero chance of hallucination.

Can I see holidays for any date?

Yes. Use the date picker to see holidays for any past or future date. The holiday data includes rules going back many years and forward (based on established calendar rules such as "2nd Monday of March").

How often is the data updated?

The holiday data is embedded in the date-holidays library version deployed with this tool. Major updates occur when countries change holiday laws. The current version covers holidays through 2026.
