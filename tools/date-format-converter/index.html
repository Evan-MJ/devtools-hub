What date formats does this tool support?

This tool auto-detects and converts between 15+ formats including: ISO 8601 (YYYY-MM-DD, YYYY-MM-DDTHH:mm:ss), US (MM/DD/YYYY), EU/UK (DD/MM/YYYY), Chinese (YYYY年MM月DD日), RFC 2822 (Mon, 25 Dec 2024 14:30:00 +0000), Unix timestamps (seconds and milliseconds), and custom patterns using date-fns tokens.

How does auto-detection work?

The tool tries multiple parsing strategies in order: ISO 8601 (native Date.parse), Unix timestamp detection (10/13 digit numbers), RFC 2822, common US/EU/Chinese patterns, and flexible parsing. The first successful parse determines the detected format.

Can I convert multiple dates at once?

Yes! Use the "Batch Convert" tab. Paste up to 100 dates (one per line) and convert them all to a single target format, or use a custom pattern. Each date is parsed independently with auto-detection.

Does this tool handle timezones correctly?

Yes. You can select a source timezone for the input date and the tool will convert to the target timezone. By default, it uses your browser's local timezone. For Unix timestamps, the timezone applies to the formatted output.

Is my data private?

100% private. All conversion happens in your browser using JavaScript. No data is sent to any server. The tool works offline after the initial page load.

What format tokens are supported?

This tool uses a subset of date-fns tokens: yyyy, yy, MMMM, MMM, MM, dd, EEEE, EEE, HH, hh, mm, ss, SSS, X, x, zzz, Z, a. For example, yyyy-MM-dd HH:mm:ss produces 2024-12-25 14:30:00. Single-letter tokens (M, d, H, h, m, s) are not supported to avoid conflicts with longer tokens.
