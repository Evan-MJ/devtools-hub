What is a JSON Schema Generator?

A JSON Schema Generator is a tool that infers a JSON Schema from a sample JSON document. Instead of writing schema syntax by hand, you paste a sample of the JSON your API or application produces, and the tool walks the structure to derive the type, properties, required fields, and array item types.

This is the natural counterpart to the JSON Schema Validator. The validator answers "does this data conform?"; the generator answers "what contract should I write?". Both are deterministic, both run on structured data, and both are the right way to keep API contracts honest.

Why AI Cannot Infer a JSON Schema Reliably

Large Language Models, such as ChatGPT, Claude, and Gemini, are not reliable schema inferrers. They can pattern-match superficially and produce plausible looking JSON Schema that is wrong about nested objects, array item types, or required fields. On deeply nested payloads they drift, and asking the same question twice yields different schemas.

Inference is a traversal problem, not a language problem. The correct algorithm is deterministic: read the JSON, recurse over objects and arrays, and emit JSON Schema keywords. Because it is a pure function of the input bytes, the output is reproducible and auditable.

The inference here runs entirely in your browser. Nothing you paste is transmitted to a server, stored, or logged, and the generated schema can be copied out and used with any JSON Schema validator or with OpenAPI 3.1, which adopts JSON Schema Draft 2020-12.

How to Use

  1. Paste your sample JSON data into the Sample JSON Data pane
  2. Click Generate Schema — the inferred schema is written to the Generated JSON Schema pane
  3. Copy the generated schema with Copy Schema and paste it into your validator, linter, or API tooling

Inferred Schema Keywords

  • object — with a properties map and a required array for every present key
  • array — with an items schema inferred from the first element
  • string / number / integer / boolean / null — by runtime type, with integers distinguished from numbers

Frequently Asked Questions

What JSON Schema draft does the generator emit?

The generator emits Draft-07 (https://json-schema.org/draft-07/schema#) for maximum compatibility with existing validators, linters, and OpenAPI 3.0 tooling. If you need Draft 2019-09 or 2020-12 semantics, post-process the emitted schema.

Does my JSON data leave the browser?

No. The inference runs client-side on the parsed value. Nothing is uploaded, stored, or shared, and the result is copied to the clipboard only when you ask for it.

How are nested objects and arrays inferred?

Objects become an type: object schema with a properties entry per key and required listing the present keys. Arrays become type: array with items inferred from the first element.

Can I use the generated schema with OpenAPI?

Yes. OpenAPI 3.1 uses JSON Schema Draft 2020-12 natively, so an inferred Draft-07 schema can be mapped forward. For full OpenAPI document validation, use a dedicated OpenAPI linter alongside this generator.

What is the difference between inferring and writing a schema by hand?

Inference is fast and good for samples; hand written schemas are precise and good for contracts. Use the generator to bootstrap a schema from real traffic, then tighten it by hand for required fields and constraints.
