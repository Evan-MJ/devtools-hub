Encode or Decode URL

What is URL Encoding?

URL encoding converts special characters into a format that can be transmitted over the Internet. Spaces become %20, and characters like &, ?, # are encoded because they have special meaning in URLs.

Characters That Need Encoding

Spaces " " Becomes: %20
Special Characters & ? # = $ + , / : ; Encoded because they have reserved meaning in URLs
Unicode Characters 你好世界 Encoded as UTF-8 byte sequences

Safe Characters

Only a limited set of characters (A-Z, a-z, 0-9, -, _, ., ~) are safe in URLs without encoding. All other characters should be percent-encoded using UTF-8 byte sequences.

Common Use Cases

  • Form Submission: Query parameters in URLs with special characters
  • API Endpoints: Construct URLs with dynamic path parameters
  • Redirect URLs: Handle URLs with query strings and fragments
  • HTML Links: Generate safe URLs for web pages

Important Notes

URL encoding is NOT the same as Base64 encoding. URL encoding uses percent-encoding (%20 for space), while Base64 uses a different alphabet and is used for encoding binary data as ASCII text.

When encoding for query parameters, use encodeURIComponent() to properly encode all special characters including & and =.
