Why URL Encoding Exists

URLs were designed to transport ASCII characters safely, but the web contains billions of pages with non-ASCII characters (Chinese, Arabic, emojis) and special symbols. URL encoding (percent-encoding) converts problematic characters into a format that URLs can handle.

The Percent-Encoding Mechanism

Each special character becomes % followed by its two-digit hex ASCII code. A space becomes %20, an ampersand becomes %26, and so on. This encoding happens at the browser level when you submit forms or navigate to URLs containing special characters.

Common Encodings

CharacterEncodedCommon Use
Space%20Between words
!%21Negation, factorials
#%23Fragment identifiers
&%26Parameter separators
=%3DKey-value pairs
/%2FPath segments
?%3FQuery string start

Real Problems Without Encoding

Search Query Failure: A search for "coffee & tea" in a URL without encoding breaks the query string. The & gets interpreted as a parameter separator, creating malformed server requests.

Path Interpretation: A filename containing /backup/important.txt in a URL path gets split into separate path segments, pointing to non-existent directories.

XSS Vulnerabilities: Without proper encoding, malicious scripts can inject code through unvalidated URL parameters. Server-side encoding prevents this by treating user input as literal data, not executable code.

Query String vs Path Encoding

Different URL components have different encoding rules:

  • Query parameters: Encode most characters, preserve =, &, + for structure
  • URL path: Encode / only when it's part of the data, not a path separator
  • Fragment: Rarely encoded, # marks the fragment start

JavaScript Encoding Functions

encodeURIComponent("hello world") → "hello%20world"

encodeURI("hello world") → "hello%20world"

Difference: encodeURI() preserves characters like /, :, ; that are valid in full URLs but are invalid in URL components.

URL Encoding in APIs

REST APIs often require query parameters to be encoded. A Twitter API request to search for "web development #tutorial" becomes:

GET /tweets?q=web%20development%20%23tutorial

Failing to encode the hashtag results in #tutorial being interpreted as a fragment identifier, causing the request to fail or return unexpected results.
