How Background Removal Works

This tool uses an edge-color sampling algorithm that runs entirely in your browser using the Canvas API. When you load an image, the script first samples eight reference points along the borders (the four corners plus the midpoints of each side) and averages their RGB values to estimate the background color. It then walks every pixel in the image and computes the Euclidean distance in RGB space between that pixel and the sampled background. If the distance is below a threshold of 60 units (calibrated for typical JPEG compression noise), the pixel is treated as background and its alpha channel is set to zero.

The result is a transparent PNG with a checkerboard pattern visible wherever the background used to be. This approach works best for product photos on solid white, light gray, or pastel backgrounds where the subject has clearly different colors. It works less well for hair, fur, transparent objects, or images where the subject colors are close to the background. For those cases a neural-network-based model like remove.bg is usually required, but for the common case of simple product shots this tool produces clean results in under a second.

Frequently Asked Questions

What image formats are supported?

Any browser-decodable format including JPEG, PNG, WebP, BMP, and GIF. Animated GIFs are processed as their first frame. Output is always a 32-bit PNG with an alpha channel so transparency is preserved when you drop the image into Photoshop, Figma, or any other design tool.

Is there a file size limit?

The tool accepts images up to 20 megabytes. Larger images are rejected with an alert. Because processing is single-pass and synchronous, very large images (over 8 megapixels) may take a few seconds but will still complete in your browser without any upload.

Are my images uploaded to a server?

No. The entire background-removal algorithm runs on-device using the Canvas API. Your images never touch our servers, never touch a third-party API, and never leave your computer. You can verify this by opening your browser DevTools Network tab and watching zero requests fire when you click Remove Background.

How does this differ from remove.bg or Photoshop?

remove.bg uses a deep neural network trained on millions of labeled images and handles complex edges like hair and fur. Our algorithm is much simpler (edge-color sampling) and works best on solid backgrounds. The trade-off is that ours is 100% free, unlimited, watermark-free, and works fully offline. For product photography on white backgrounds, the quality is comparable.

Why is the result a PNG with transparency?

PNG supports an alpha channel that lets pixels be partially or fully transparent. When you place the result on a colored background in any design tool, the original background color shows through. If you need a flat solid color background instead, open the result in any image editor and add the background layer you want.

Can I batch-process many images at once?

Not in this tool. It processes one image at a time so you can verify each result. If you need batch processing, you can chain the tool with a local script using a headless browser, or use a dedicated desktop app.
