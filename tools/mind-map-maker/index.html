Is the Mind Map Maker really free?

Yes. The tool is 100% free with no signup, no daily limit, no watermark, no upsell, and no account. You can build unlimited mind maps with unlimited nodes. Everything renders locally in your browser using SVG, so there is no server cost for us to pass on.

Do I need to upload my ideas anywhere?

No. The mind map is rendered locally in SVG. Your text, structure, and edits stay in your browser. We autosave to localStorage so a refresh does not lose your work, but nothing is sent to a server, no cloud save, no analytics on your map content.

How is this different from MindMeister, Coggle, or Miro?

Most popular mind map tools require a signup, put a node limit on the free tier, or paywall export to PNG and PDF. This tool is fully usable with no account, unlimited nodes, no node count, all five export formats unlocked, and runs entirely client-side. AI chatbots cannot draw, drag, or interactively edit a mind map for you the way this tool does.

What keyboard shortcuts are supported?

Tab adds a child node to the selected node. Enter adds a sibling. F2 starts inline rename on the selected node. Delete removes the selected node and its subtree. Space or double click starts inline edit. Arrow keys move the selection. Ctrl+S opens the export menu. Ctrl+Z and Ctrl+Y undo and redo. Hold Space and drag the canvas to pan.

Can I import an existing mind map or outline?

Yes. Paste a Markdown outline where each heading level becomes a node, or paste an OPML file exported from any other mind map tool, or paste a JSON document from a previous export of this tool. The importer turns your outline into a fully laid-out mind map in one click.

Can I export to PNG, SVG, Markdown, OPML and JSON?

Yes. Export PNG renders the canvas at 2x resolution for slides and documents. Export SVG produces a clean, scalable vector file that opens in Figma, Illustrator, or Inkscape. Export Markdown gives you a clean indented outline. Export OPML is compatible with most other mind mapping tools. Export JSON saves the full structure for later re-import.

Does this work on mobile and tablet?

Yes. The canvas responds to single-finger drag for panning, pinch for zooming, and a long press to add a new node. The layout adapts to small screens with the toolbar collapsing into a drawer.
