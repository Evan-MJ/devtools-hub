Generate Hash

Cryptographic hash functions convert input data into a fixed-length fingerprint. The same input always produces the same hash output. Hashes are one-way functions—it's computationally infeasible to reverse them.

MD5 produces 128-bit hashes (32 hex characters) but is cryptographically broken. SHA-1 produces 160-bit hashes and is also deprecated for security use. SHA-256 and SHA-512 are currently considered secure for most applications.

Common use cases include password storage (use bcrypt/scrypt instead for passwords), file integrity verification, digital signatures, and blockchain technology. Never use these hashes for password storage in new systems.
