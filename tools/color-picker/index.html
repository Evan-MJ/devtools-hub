Understanding Color Formats

Different systems represent colors in different formats. Web browsers use HEX and RGB, design tools often use HSL, and print systems work with CMYK. Understanding these formats helps you convert between them accurately.

HEX Color Codes

HEX codes represent colors as hexadecimal triplets: #RRGGBB. Each pair ranges from 00 to FF (0-255 in decimal). The most common format for web development, CSS, and design tools.

  • #FF0000 = Pure red
  • #00FF00 = Pure green
  • #0000FF = Pure blue
  • #000000 = Black
  • #FFFFFF = White

RGB Color Model

RGB defines colors by their Red, Green, and Blue components, each ranging from 0-255. Combining all three at maximum (255,255,255) produces white. All at zero (0,0,0) produces black.

The formula for perceived brightness: (R×299 + G×587 + B×114) / 1000. Colors with brightness above 128 are typically considered "light" colors.

HSL Color Model

HSL represents colors through Hue (color angle 0-360°), Saturation (intensity 0-100%), and Lightness (brightness 0-100%). HSL is often more intuitive for humans - "make it more blue" or "desaturate this" maps directly to HSL adjustments.

  • Hue 0° = Red
  • Hue 120° = Green
  • Hue 240° = Blue

Accessibility: Contrast Ratios

Web Content Accessibility Guidelines (WCAG) require minimum contrast ratios between text and background colors for readability:

LevelNormal TextLarge Text
AA (Minimum)4.5:13:1
AAA (Enhanced)7:14.5:1

Use the relative luminance formula to calculate: L = 0.2126 * R + 0.7152 * G + 0.0722 * B where R, G, B are linearized values.

Alpha (Transparency)

RGBA and HSLA add an alpha channel (0-1) for transparency. CSS also supports 8-digit HEX (#RRGGBBAA) for the same effect. An alpha of 0 means fully transparent, 1 means fully opaque.

Color in Web Development

CSS Variables: Define a color system with :root { --primary: #3498db; } for consistent theming.

Dark Mode: Store both light and dark values: --bg: #ffffff and --bg-dark: #1a1a2e.

Gradient Interpolation: Colors between two values in a gradient don't transition linearly in HSL space - the hue might wrap around (0° to 360°), causing unexpected color shifts.
