Pick a Color

HEX format uses hexadecimal color codes like #667eea. RGB defines red, green, blue values from 0-255. HSL defines hue (0-360), saturation (0-100%), and lightness (0-100%).

All three formats represent the same color. HEX is compact and commonly used in CSS. RGB is intuitive for programming. HSL is useful for generating color variations programmatically.

Use cases include CSS styling, design system color palette creation, accessibility checking (contrast ratios), and generating tints/shades of a base color.
