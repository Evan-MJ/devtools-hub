Frequently Asked Questions

Will my presentation be uploaded to a server?

No. The PPTX file is unzipped in your browser's memory, its XML is parsed by the page's own code, and the PDF is built by javascript in the same tab. No bytes ever leave your device, so confidential decks, client pitches and exam slides stay private. You can verify this in the browser's Network tab: after the page has loaded, the converter makes no outbound requests.

Does the PDF keep selectable text?

Yes, in the default text mode. Slide text is written straight into the PDF as real characters at real coordinates, so recipients can select, copy, search and screen-read it. The image mode instead renders each slide to a picture, which preserves complex graphics but leaves the text not selectable. You pick the mode; nothing is switched on your behalf.

Which file formats are supported?

Modern .pptx files (Office Open XML). The legacy binary .ppt format from PowerPoint 97-2003 is a different, complicated structure that this tool does not parse - resave it as .pptx in PowerPoint first. Google Slides can export PPTX via File > Download > Microsoft PowerPoint.

How faithful is the conversion compared with server converters?

The text mode draws text, shape fills and outlines, images and tables, and simplifies advanced effects such as 3-D rotation, charts, gradient fills and custom fonts. The image mode captures those details by taking a picture of the parsed slide, so it looks closer to the original but the text is not selectable. Either way, one slide becomes one page and every page keeps the slide's own size.

What happens to animations and transitions?

They are dropped, by design. A PDF is a static document, so every slide appears in its final built state with all elements visible, exactly as PowerPoint itself prints slides.

Can speaker notes be included?

Yes. Tick the speaker notes box and each slide is followed by a notes page titled with the slide number, carrying the notes text for that slide. Leave it unticked and the PDF contains slides only, one page each.

Is there a file size or page limit?

No. There is no watermark, no quota and no signup. The practical limit is your device's memory, since the whole file is processed locally; typical decks up to roughly 50 MB convert fine on a modern computer.

Why use this instead of asking an AI chatbot?

An AI chatbot cannot unzip a file, parse its shape coordinates and hand back a real PDF with exact text positions - and asking it to summarise your slides loses the original design. This page runs a deterministic conversion pipeline on your device, so the output is a genuine PDF you can print, email or submit.
