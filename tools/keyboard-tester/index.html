Why AI Cannot Test Your Keyboard

An AI chatbot has no way to reach the physical switches under your keys. Key registration is a hardware event that your browser receives directly, so only a real keyboard tester can confirm whether a key works. When your W key stops registering in games, asking a chatbot only gets you advice, not an answer. This tool listens to every key press in your browser, lights up the exact key you press, and tells you in seconds whether each key works, repeats, sticks, or ghosts. The result is deterministic — a key either registers or it does not.

How the Keyboard Tester Works

  1. Press your keys — every key on the on-screen keyboard lights up blue the moment it registers on your physical keyboard.
  2. Watch the stats — the side panel tracks keys tested, keys currently held, maximum rollover, ghost events, and stuck keys in real time.
  3. Run a full test — use Test All Keys to walk through every key in order so none get skipped, ideal for warranty checks.
  4. Export proof — generate a report listing untested keys, stuck keys, and ghost events, then attach it to a support ticket.
Which keys can I test?

Every standard keyboard key: the function row (F1-F12), number row, all letter keys, modifiers (Shift, Ctrl, Alt, Win), navigation and editing keys (arrows, Home, End, PageUp, PageDown, Delete, Insert, PrintScreen, ScrollLock, Pause), and the full numpad including NumpadEnter and NumpadDecimal.

My space bar or Enter seems broken. Will this confirm it?

Yes. Press the key repeatedly and watch whether the on-screen key lights up every time. If it lights up sometimes but not others, the switch is likely dirty or failing. If it never lights up, check for a software remap first, then a hardware fault. A key that stays lit after you release it is a stuck key.

What is rollover, and why does it matter?

Rollover is how many keys you can press at the same time and still have all of them register. A basic membrane keyboard typically registers 2-6 simultaneous keys (2KRO-6KRO), while gaming and mechanical keyboards often support N-key rollover (NKRO). Hold several keys at once and this tester shows your maximum in real time, which is useful for games that need many simultaneous presses.

Why does the Win key not always light up?

The Windows/Meta key is intercepted by your operating system before it reaches the browser, so on Windows pressing Win alone opens the Start menu and may not register here. The same is true for some Fn and media keys on laptops. This is an OS limitation, not a keyboard fault. You can still test the key if you press it in combination with another key.

Can I use this on a phone or tablet?

Yes. If you connect an external keyboard to a phone or tablet over USB or Bluetooth, this tester works on Android and iOS too, since it relies on standard browser keyboard events. The on-screen layout reflows to fit smaller screens.
