    Frequently Asked Questions

    Will my photos be uploaded to a server?

    No. The entire conversion happens in your browser using the heic2any library (libheif compiled to WebAssembly). Your files are read with the File API, decoded locally, and saved as JPEG. No bytes ever leave your device. You can verify this by checking the Network tab in your browser's DevTools.

    Does this work with Live Photos?

    HEIC files from Live Photos contain both the image and a short video. heic2any extracts only the still image from the HEIC container, discarding the motion component. The result is a standard JPEG still photo.

    Will I lose image quality?

    HEIC uses more advanced compression than JPEG, so the JPEG output will typically be larger. However, our default quality setting of 92% preserves excellent visual quality. You can adjust the quality slider from 50% (smaller file, more compression) to 100% (largest file, best quality).

    Why is my JPG file larger than the original HEIC?

    This is normal. HEIC (HEIF) is a modern format that compresses images about 50% more efficiently than JPEG for the same quality. Expect the resulting JPG to be 1.5–2.5x larger than the original HEIC. This is the trade-off for universal compatibility.

    How many photos can I convert at once?

    There is no limit. You can select and convert as many HEIC photos as you want. For large batches, conversion may take a moment since each file is decoded locally. The ZIP download option makes it easy to save all converted files at once.

    Which browsers support this tool?

    Any modern browser with WebAssembly support: Chrome, Firefox, Safari, Edge, and Opera. Safari on macOS and iOS supports HEIC natively. Chrome on desktop uses the WebAssembly decoder. Internet Explorer is not supported.

    Does the tool preserve EXIF/metadata?

    heic2any preserves most EXIF data including orientation, camera model, date taken, and GPS location. Color profiles are also transferred to the output JPEG.
