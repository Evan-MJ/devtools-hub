What is a UUID?

UUID (Universally Unique Identifier) is a 128-bit label used to identify information in computer systems. UUIDs are standardized by RFC 4122 and come in several versions, each with different generation methods and properties.

UUID Versions Explained

UUID v4 (Random) xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx Most commonly used. Random generation means collision probability is negligible.
UUID v1 (Timestamp) xxxxxxxx-xxxx-1xxx-xxxx-xxxxxxxxxxxx Embeds timestamp and MAC address. Can be sorted chronologically.
UUID v7 (Unix Epoch) xxxxxxxx-xxxx-7xxx-xxxx-xxxxxxxxxxxx Newer standard. Combines Unix timestamp with randomness. Sortable and time-ordered.

UUID Format Details

In UUID v4, the x characters are replaced with random hexadecimal digits, while y is always 8, 9, a, or b. This specific pattern (4xxx-yxxx) identifies the version of the UUID.

UUID v1 includes the node (MAC address of the generating machine) and timestamp. UUID v7 uses Unix timestamp in milliseconds, providing better sorting capabilities while maintaining privacy since it doesn't expose the MAC address.

Common Use Cases

  • Database Primary Keys: Generate unique identifiers for database records without a central coordinator
  • Distributed Systems: Create identifiers across multiple systems without collision
  • Session IDs: Generate unique session identifiers for web applications
  • Resource Naming: Name files, containers, or resources with guaranteed uniqueness

Security Considerations

While random UUIDs (v4) are not predictable, they should not be used for security-critical purposes like cryptographic keys or security tokens. For those use cases, use cryptographically secure random number generators instead.
