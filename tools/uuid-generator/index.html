Generate UUID

UUID (Universally Unique Identifier) is a 128-bit label. UUID v4 is random and most commonly used—collision probability is negligible. UUID v1 embeds timestamp and MAC address. UUID v7 is newer, combining timestamp with randomness.

UUID v4 format: xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx where y is 8, 9, a, or b. UUID v1 format includes node (MAC address) and timestamp. UUID v7 uses Unix timestamp in milliseconds.

Common use cases include database primary keys, distributed systems identifiers, session IDs, and resource naming. While random UUIDs are not predictable, don't use them for security-critical purposes.
