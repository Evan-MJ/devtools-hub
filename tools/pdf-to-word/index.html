What does this tool do?

PDF to Word Converter extracts text from any PDF document and generates an editable Word file (.docx), RTF, or plain text file. The conversion runs entirely in your browser using pdf.js to parse the PDF and the docx JavaScript library to build the Word file. The output preserves paragraph structure and detects headings based on font size, so you get a real editable document, not a flat text dump.

3 output formats explained

  • DOCX (Word) — Best quality. The native Microsoft Word format. Opens in Word, Google Docs, LibreOffice Writer, and Apple Pages. Paragraphs and heading levels (detected from font size) are preserved. Use this when you need to keep editing the document.
  • RTF (Rich Text Format) — Universal compatibility. A simpler format that opens in virtually any text editor on any platform. Smaller than DOCX. Good for sharing when you are not sure what software the recipient has.
  • TXT (Plain Text) — Fastest. Pure text with no formatting. Use this when you only need the words and want the smallest possible file.

How it works

  1. Upload any PDF (up to 100 MB). Your file never leaves the browser.
  2. Choose an output format — DOCX, RTF, or TXT.
  3. Click Convert to Word — pdf.js parses every page and extracts text positions.
  4. Preview and edit the extracted text in the in-browser editor if needed.
  5. Download your editable Word document, ready to open in Word, Google Docs, or LibreOffice.

What AI cannot do here

Large Language Models like ChatGPT, Claude, and Gemini can read text from PDFs and even rewrite the content, but they cannot generate a valid .docx file. The Word format is a complex ZIP archive containing XML, styles, relationships, fonts, and embedded media. AI text generation produces text, not binary documents. This tool runs the actual conversion pipeline in your browser using the same open-source libraries that power many desktop applications.

Frequently asked questions

Will my PDF be uploaded to a server?

No. The entire conversion pipeline runs in your browser. The PDF is read with the standard File API, parsed by pdf.js to extract text and font positions, and a Word document is generated client-side using the docx JavaScript library. No bytes leave your device. You can confirm this in your browser's DevTools Network tab — you will see zero outbound requests for the file content.

What's the maximum file size?

We support PDFs up to 100 MB. The limit is browser memory. For very large files, processing may take longer but will still complete. The file never leaves your device, so there is no upload time. If the browser runs out of memory, try splitting the PDF first with our PDF Splitter tool.

What's the difference between DOCX, RTF, and TXT?

DOCX is Microsoft Word's native format. It opens in Word, Google Docs, LibreOffice, and Apple Pages. Headings, paragraphs, and text styling are preserved. RTF (Rich Text Format) is a simpler format that opens in any text editor. TXT is plain text only — no formatting. Use DOCX for editable Word documents, RTF for universal compatibility, TXT for fastest conversion.

Can I edit the text before downloading?

Yes. After conversion, the extracted text appears in an editable preview area. You can modify, add, or delete any text before clicking Download. This is useful for fixing OCR errors or removing unwanted sections. The Regenerate button rebuilds the DOCX from your edited text.

Will formatting like tables and images be preserved?

Paragraphs and heading structure (detected from font size) are preserved in DOCX output. Images and complex table layouts are not extracted in this version — the focus is on fast, accurate text extraction with paragraph structure. For full layout preservation including images, you would need a paid desktop application like Adobe Acrobat.

Why can't AI chatbots convert my PDF to Word?

AI assistants like ChatGPT, Claude, and Gemini can read text from PDFs and even summarize or rewrite the content, but they cannot generate a valid .docx file. The Word format (.docx) is a complex ZIP archive containing XML, styles, relationships, fonts, and embedded resources. AI text generation produces text, not binary documents. This tool runs the actual conversion pipeline in your browser using the docx JavaScript library, the same technology that powers many professional desktop applications.
