What is a Unix Timestamp?

A Unix timestamp is the number of seconds elapsed since January 1, 1970 00:00:00 UTC. Many programming languages and APIs use this format for date storage because it's easy to compare and calculate with.

Seconds vs Milliseconds

JavaScript (Milliseconds) Date.now() → 1747488000000 13 digits - multiply by 1000 to convert to seconds
Python, Go, Ruby (Seconds) time.time() → 1747488000 10 digits - standard Unix format
Java (Milliseconds) System.currentTimeMillis() → 1747488000000 Uses milliseconds like JavaScript
Database Integers PostgreSQL: EXTRACT(epoch FROM now()) Most databases store as integers

How Timestamp Conversion Works

To convert a Unix timestamp to a date, the seconds value is multiplied by 1000 (to get milliseconds) and passed to the Date constructor. The Date object then converts it to a human-readable string using the local timezone or UTC.

To convert a date to a timestamp, the Date object retrieves the milliseconds since epoch using getTime(), then divides by 1000 to get seconds. This ensures compatibility with Unix-based systems.

Common Use Cases

  • API Integrations: Many REST APIs accept or return timestamps in Unix format for universal compatibility
  • Database Records: Store creation and update times as integers for efficient querying and indexing
  • Log Files: Parse server logs by converting timestamps to human-readable dates for debugging
  • Scheduling Systems: Cron jobs and task schedulers often use Unix timestamps for next-run calculations
