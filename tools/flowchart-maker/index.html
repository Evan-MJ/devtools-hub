How it works

The canvas is a single SVG document that you edit directly. Pick a shape from the palette (or press its letter key) and it drops onto the canvas at a free spot. Drag any node with the mouse or your finger and every arrow attached to it follows, because the edges are re-computed from node positions on every move.

To draw an arrow, press Connect, click the source node and then the target node. A decision node can have as many outgoing arrows as you need. Double-click a node to rename it — Enter confirms, Esc cancels. Select a node or an arrow and press Delete (or the Delete button) to remove it; deleting a node removes its arrows too.

Your work is autosaved to this browser's local storage, so a reload or a closed tab brings the flowchart back. New / Clear wipes the canvas and the saved copy.

Export

  • Export SVG downloads a self-contained vector file with the node shapes, labels and arrows — open it in Figma, Illustrator, Inkscape or a browser.
  • Copy Mermaid puts valid flowchart TD source on your clipboard so you can paste it into GitHub, Notion, GitLab or any Markdown tool that renders Mermaid.
  • Download .mmd saves the same Mermaid source as a file.

Privacy

This editor is plain HTML, CSS and JavaScript — no server, no API, no analytics and no external requests. Your flowchart is drawn locally and the autosave lives only in this browser's local storage, which you can wipe at any time with New / Clear. Nothing you draw is ever transmitted.

Frequently Asked Questions

Is this flowchart maker really free?

Yes — 100% free, with no signup, no account, no watermark and no usage limit. There is no paid tier and no upsell.

Does my flowchart get uploaded anywhere?

No. The whole editor is plain HTML, CSS and JavaScript running in your browser tab. There is no server call, no external script, no CDN and no analytics on your diagram. The flowchart only ever exists in your browser's memory and in this browser's local storage.

Which node shapes are available?

Five: Start/End (rounded), Process (rectangle), Decision (diamond), Input/Output (parallelogram) and Document/Note (wavy bottom). Each one maps to a matching Mermaid shape in the exported code.

Can I use it on a phone?

Yes. The layout collapses to a single column, the palette becomes a horizontally scrollable strip and nodes are dragged with touch. Because of the smaller screen, double-tapping a node to rename it can be finicky — the Edit label button does the same job with one tap.

How do I undo a mistake?

Press Undo or Ctrl/Cmd + Z. The editor keeps a stack of the last 50 changes, so you can step back through several edits.

Will my work still be there tomorrow?

Yes, as long as you come back to the same browser on the same device and do not clear site data. The save lives in local storage under this site only — no account needed. Exporting to SVG or Mermaid gives you a permanent copy you control.

Does the Mermaid export include my node positions?

No — Mermaid renders its own layout, so the export contains the structure (nodes, labels and the connections between them) rather than pixel positions. Use the SVG export when you need the exact layout you drew.
