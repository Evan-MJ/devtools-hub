How does this keyword research tool work?

This tool queries 7+ free data sources in parallel to find keyword opportunities:

  • Google Trends RSS - Daily trending searches with traffic gradients (100+, 500+, 1000+, 2000K+)
  • Bing Autosuggest - Real search suggestions from Bing with HCS (High Confidence Score) indicators
  • Google Autosuggest - Google's search suggestions via suggestqueries API
  • Datamuse API - Semantic related words with frequency scores (ml, sl, lc, rc, rel_syn, rel_jjb, rel_jja parameters)
  • Wikipedia Most Read - Daily most-read articles with exact view counts
  • HackerNews API - Top tech stories with scores and comment counts
  • GitHub Trending - Trending repositories with star counts

All requests run client-side in your browser. No data leaves your device except the API calls to these public endpoints.

What do the score/volume columns mean?
  • Google Trends: Traffic gradient (100+ = low, 500+ = medium, 1000+ = high, 2000K+ = viral)
  • Bing/Google Autosuggest: HCS (High Confidence Score) - higher means more popular suggestion
  • Datamuse: Frequency score (~100M = very common, ~100 = rare). Not search volume but linguistic frequency.
  • Wikipedia: Exact daily page views
  • HackerNews: Story score (upvotes - downvotes)
  • GitHub: Star count

Use these as relative indicators, not absolute search volumes. For precise volumes, use paid tools like Ahrefs or SEMrush.

How to use this for SEO content strategy?
  1. Enter a seed keyword related to your niche (e.g., "ai writing", "seo audit", "keyword research")
  2. Review Autosuggest tab for what people actually type after your keyword
  3. Check Related Terms for semantic variations and LSI keywords
  4. Monitor Trending for emerging topics from Google Trends, HN, GitHub, Wikipedia
  5. Use Questions tab (derived from autosuggest "how/what/why" patterns) for FAQ content
  6. Export to CSV for further analysis in your preferred SEO tool
Is this tool really free and private?

Yes. No signup, no account, no tracking. All API calls go directly from your browser to the public endpoints. Your seed keyword never touches our servers. The tool runs entirely client-side.

Why combine multiple sources instead of using one?

Each source captures different intent signals:

  • Autosuggest = what users start typing (navigational/commercial intent)
  • Related terms = semantic relationships (informational intent)
  • Trending = what's hot right now (temporal intent)
  • Questions = problem-solving intent (long-tail, voice search)

Combining them gives a 360° view no single source provides.
