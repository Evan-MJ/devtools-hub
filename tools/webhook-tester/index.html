How does this work?

Click "Generate Webhook URL" to create a unique endpoint. Send HTTP requests (POST, GET, PUT, DELETE, etc.) to that URL from your application, CI/CD pipeline, or testing tool. All requests are captured and displayed here in real-time with full headers, query parameters, and body content.

Is my data private?

Yes. Requests are stored temporarily in Cloudflare KV with a 7-day TTL and a maximum of 100 requests per endpoint. No signup is required, no data is logged permanently, and endpoints are not shared. Each endpoint uses a cryptographically random ID that cannot be guessed.

What request types are supported?

All HTTP methods (GET, POST, PUT, PATCH, DELETE, HEAD, OPTIONS, etc.). The body is captured as raw text and parsed as JSON when applicable. Query parameters, headers, and IP address are all recorded.

How do I test with cURL?

Click the "cURL" tab on any captured request to see the exact cURL command to reproduce it. You can also use the "Copy URL" button and construct your own requests.

Can I use this for production webhooks?

This tool is designed for development and testing only. Endpoints expire after 7 days and are limited to 100 requests. For production use, consider services like webhook.site, ngrok, or your own infrastructure.
