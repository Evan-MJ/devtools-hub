What is Base64 Encoding?

Base64 encoding converts binary data into ASCII text format using 64 characters (A-Z, a-z, 0-9, +, /). Each Base64 digit represents exactly 6 bits of the original data. This encoding is essential when transmitting data through protocols that only support text.

Common Use Cases

Email Attachments (MIME) Email attachments are encoded in Base64 to ensure they can be transmitted via email protocols that only support text.
Data URIs in CSS/HTML Embed small images directly in HTML or CSS using Base64 data URIs to reduce HTTP requests.
API Authentication Basic Auth credentials are Base64 encoded (e.g., "user:pass" becomes "dXNlcjpwYXNz"). Note: This is NOT encryption.
Storing Binary in JSON When APIs need to transmit binary data as JSON, Base64 encoding is commonly used to represent the binary content as text.

URL-Safe Variant

Standard Base64 uses + and / which can conflict with URL reserved characters. For URL-safe encoding, variant uses - and _ instead. This is commonly used in URL-safe tokens and JWTs.

Important Notes

  • Not Encryption: Base64 is NOT encryption—anyone can decode it trivially. Never use it to protect sensitive data.
  • Size Overhead: Base64 increases data size by approximately 33% compared to the original binary data.
  • Browser Support: Works in all modern browsers using the built-in btoa() and atob() functions.
