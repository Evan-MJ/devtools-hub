Encode or Decode

Base64 encoding converts binary data into ASCII text format using 64 characters (A-Z, a-z, 0-9, +, /). Each Base64 digit represents exactly 6 bits of the original data. This encoding is essential when transmitting data through protocols that only support text.

Common use cases include email attachments (MIME), embedding images in CSS/HTML as data URIs, API authentication (Basic Auth uses Base64), and storing binary data in JSON. Base64 is NOT encryption—anyone can decode it trivially.

Standard Base64 uses + and / which can conflict with URL reserved characters. For URL-safe encoding, variant uses - and _ instead. Base64 increases data size by approximately 33%.
