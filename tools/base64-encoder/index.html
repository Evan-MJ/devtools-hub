Understanding Base64 Encoding

Base64 represents binary data in ASCII string format by translating it into a radix-64 representation. Each Base64 digit represents exactly 6 bits of the original data. This encoding exists because some protocols and systems only handle text data, rejecting raw binary bytes.

How Base64 Works

When you encode "Hello" to Base64:

  1. Convert text to bytes: "Hello" → [72, 101, 108, 108, 111]
  2. Group 6 bits: 010010 000110 010110 101100 011011 011011 011000
  3. Map to characters: SGVsbG8
  4. Add padding if needed: SGVsbG8=

When to Use Base64 Encoding

Email Attachments (MIME)

Base64 encoding has been the standard for email attachments since 1991. When you send a PDF or image via email, it's converted to Base64 text to travel safely through SMTP servers that only accept 7-bit ASCII characters.

Data URIs for Images

Embedding small images directly in HTML/CSS using data:image/png;base64,iVBORw0KG... eliminates extra HTTP requests. This technique works particularly well for icons and small graphics where the Base64 overhead is less than the latency cost of separate requests.

API Authentication

Many REST APIs use Basic Authentication, which requires Base64 encoding of "username:password" credentials. While not encryption, it provides a standardized format for transmitting authentication data.

JSON Data Storage

When storing binary data in JSON (such as image thumbnails or document signatures), Base64 encoding allows the binary content to be represented as a portable text string.

The 33% Size Increase Problem

Base64 encoding always increases data size by approximately 33%. This happens because every 3 bytes (24 bits) of original data becomes 4 Base64 characters (24 bits again), but with a reduced alphabet. Plus, padding characters may be added.

Standard vs URL-Safe Base64

Standard Base64 uses A-Za-z0-9+/ plus = for padding. However, these characters can cause issues in URLs:

  • + and / are reserved characters in URLs
  • Some systems interpret = as parameter separators

URL-safe Base64 replaces + with - and / with _, eliminating padding by using alternative length calculation.

Base64 Encoding in Different Languages

JavaScript: btoa("Hello") or Buffer.from("Hello").toString("base64")

Python: import base64; base64.b64encode(b"Hello")

Node.js: Buffer.from("Hello").toString("base64")

Security Considerations

Base64 is NOT encryption. Anyone can decode a Base64 string trivially. Never use Base64 to hide sensitive data like passwords or tokens. For encryption, use AES, RSA, or similar cryptographic algorithms. Base64 is purely an encoding mechanism for data transport.
