How It Works

1. Drop or select a video file (MP4, WebM, MOV, AVI)
2. Set the start and end time in seconds
3. Click "Cut Video" — FFmpeg.wasm runs entirely in your browser
4. Download the trimmed video

Privacy: All processing happens in your browser. No video is uploaded to any server.

What formats are supported?

Input: MP4, WebM, MOV, AVI, MKV (any format FFmpeg supports). Output: MP4 (H.264/AAC).

Is there a file size limit?

Browser memory is the limit. Files under 500MB work best on modern devices.
