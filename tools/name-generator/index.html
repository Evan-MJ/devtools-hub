How It Works

The name generator uses a deterministic algorithm that combines curated word lists with CVCV (consonant-vowel-consonant-vowel) syllable assembly and Markov-style word part concatenation. Each category draws from a dedicated word list tuned to its style:

  • Fantasy: Syllable patterns for human/elf/dwarf/orc/dragonborn names; compound word generator for places; deterministic phrase assembler for taverns.
  • Baby: 350+ curated names from public SSA data tagged with origin (English/Latin/Greek/Hebrew/Arabic/Sanskrit/Celtic) and meaning.
  • Business: Industry keyword database × suffix pattern table (Tech + -ly, Food + -hub, Health + -lab).
  • Brand: Markov-chain-style root concatenation with startup-style suffixes (-ify, -verse, -wave, -hub).
  • Username: Adjective + noun + numeric/digit suffix generator tuned per platform aesthetic.
  • Character: Genre × era word matrix with realistic-sounding Latin, English, French, German, and Slavic patterns.
  • Fake: Realistic country-specific first + last name pools covering USA, UK, Canada, Australia, France, India, Germany, Japan.

Are the names uploaded to a server?

No. Every word list is embedded inline as JavaScript constants. The selection algorithm runs in your browser. You can verify by opening DevTools Network tab while generating - no upload requests appear. Your names and any search keywords stay on your device.

Can I save my favorite names?

Yes, click the star icon on any name to add it to your session favorites. Favorites persist across regenerations within the same browser session via localStorage. Clearing browser data clears favorites - this is by design for privacy.

How do I copy all names at once?

Click the Copy All button in the output panel. The names are copied as a newline-separated list, ready to paste into a document, spreadsheet, or chat. Single-name copy is also available by clicking the copy icon next to each name.

Can I filter by first letter or name length?

Yes. Both filters are available in the customization panel. First-letter filter accepts any letter A-Z. Length filter accepts a min and max character count from 3 to 14. Pronounceability toggle filters names that have three or more consecutive consonants.

Does this work offline?

Yes. Once the page loads, you can disconnect from the internet and continue generating names. All word lists are embedded inline. No server round-trip, no API calls, no analytics beyond the site's cookieless page-view counter.

How many names can I generate at once?

Use the Count slider to set 5, 10, 25, 50, or 100 names per click. The algorithm deduplicates internally so you get unique names each batch. After generation, click again to append another batch without losing earlier names.
