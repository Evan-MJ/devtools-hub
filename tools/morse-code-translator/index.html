What is Morse Code?

Morse code is a method of transmitting text information as a series of on-off tones, lights, or clicks. Each letter, number, and punctuation mark is represented by a unique sequence of dots (.) and dashes (-). Originally invented for telegraph communication in the 1830s-1840s, it remains an important skill for emergency communication and hobbyists.

Frequently Asked Questions

Is Morse code still used today?

Yes, though less common for mainstream communication. It's still used in amateur radio, emergency signaling, and military applications.

What does SOS stand for?

SOS does not actually stand for anything. It was chosen because its pattern (...---...) is easy to remember and transmit. It became the standard maritime distress signal in 1908.

Can this tool play Morse code audio?

Yes, click the "Play Sound" button to hear the Morse code using audio beeps.
