How Email Verification Works

1 Format Check - First we verify the email has valid syntax (user@domain.com format)
2 MX Lookup - We check if the domain has mail servers configured to receive email
3 SMTP Connect - We connect to the mail server and ask if this mailbox exists (without sending an email)
4 Risk Assessment - We check for disposable domains, role accounts, and other risk factors
